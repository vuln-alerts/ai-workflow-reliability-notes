# Prompt Consistency
Prompt behavior can slowly drift as workflows become larger and more dependent on context.
Even when prompts initially work well, inconsistent document structure, unclear instructions, or changing workflow conditions can create unstable outputs.

Some practical considerations:

* keeping prompts readable
* reducing unnecessary instructions
* separating operational logic from prompt wording
* maintaining reusable structures
* simplifying context handling where possible

Consistency is usually easier to maintain with smaller and clearer workflow structures.
